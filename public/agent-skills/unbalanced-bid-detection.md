# Unbalanced Bid Detection Skill

This agent skill describes how the ARBA Platform detects unbalanced bids and front-loading in construction project BOQs.

## Capability Description
- Scans all lines in Civil and Structural trades.
- Validates the unit prices against regional historical indices for Saudi Arabia.
- Enforces pro-rata distribution ceilings for early-stage works like mobilization, site preparation, and excavation.
- Flag front-loaded bids where early-stage unit prices are inflated to extract early capital.
