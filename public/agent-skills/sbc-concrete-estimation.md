# SBC Concrete & Reinforcement Estimation Skill

This agent skill describes the concrete and reinforcement estimation capabilities compliant with the Saudi Building Code (SBC).

## Capability Description
- **SBC 301 (Concrete structures):** Calculates concrete grade, pouring volume, and structural dimensions.
- **SBC 304 (Concrete reinforcement):** Calculates steel reinforcement rebar weights, overlap ratios, tie-wire requirements, and spacer block distribution.
- **Waste Factor Optimization:** Employs regional Saudi logistics and standard waste factors to optimize materials ordering, yielding up to a 15% reduction in material waste.
